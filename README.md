# IRIAMイベント管理ツール

IRIAM の企画配信で使う、達成条件の判定・カウント・ガチャ抽選を手元で回すための管理画面。
配信者が演者業に集中できるよう、進行の判断に必要な数字を1画面にまとめることを目的にしている。

**公開先**: https://kaedeno1022.github.io/iriam-event-tool/

## データの扱い

- 記録したデータ(ユーザー名・メモ・ギフト履歴・企画の設定)は**利用者のブラウザ内(localStorage)に
  のみ保存され、外部へ送信されません**。サーバもアカウントもありません。
  - 唯一の例外がパネル画像の外部URLです。設定した場合、その画像を表示する時点で
    **URL自体がリクエスト先になり**、配信元にアクセス元の情報(IPアドレス・User-Agent)が渡ります。
    参照元URLの送出は抑止していますが、アクセスそのものは画像表示に必要なため防げません。
- したがって、データは端末・ブラウザごとに独立します。別の端末で開いても同じデータは見えません。
- 「エクスポート」はJSONファイルを端末へ書き出すだけで、どこへも送信しません。
  ブラウザのデータ消去に備えて、定期的な書き出しを推奨します。
- 書き出したJSONには記録した全データが入ります。他者へ渡す場合はその点を前提に扱ってください。

通信が発生する経路(アプリ本体の取得、初回のギフト初期データ読み込み、パネル画像に外部URLを
設定した場合の画像取得)については、`仕様書.md` の8章に整理しています。

## 使い方

静的サイトなのでビルド不要。ブラウザで公開先を開けばそのまま使えます。
ローカルで動かす場合は、リポジトリ直下を任意の静的サーバで配信してください
(ES modules を使うため、`file://` で直接開くと動きません)。

```
npx serve .
```

## 開発

```
npm install
npx vitest run    # テスト実行
```

- ビルド工程なし。バニラ JS(ES modules)+ hash ベースルーティング。
- 詳細な仕様・データモデル・設計判断は `仕様書.md` を参照。
